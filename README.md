This repository holds the one-line cat joke entry for the [make.fun competition](https://make.fun/bounty/u-aldy998-the-one-line-cat-joke-that-lands-a7b18262): a single line about a cat who is not convinced her apartment counts as indoors. Running `node main.ts` writes the entry to `$OUT_DIR/entry.txt` (default `/output`) and prints it to stdout.
